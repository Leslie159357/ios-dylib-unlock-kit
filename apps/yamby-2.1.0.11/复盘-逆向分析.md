# Yamby 逆向分析报告（含最终结果）

> 目标：`com.hush.yamby`（Android Emby 客户端，`versionCode 20010012` / `versionName 2.1.0.11`）
> 工具：REA 6.5.0（provider = jadx-headless 0.7.1）+ apktool 3.0.3 + 自研字符串解密
> 日期：2026-10-15（**最终结果已实机验证**，见 §7）

---

## 1. 加固形态：娜迦 NMMP（方法虚拟化 VMP）

| 证据 | 位置 |
|---|---|
| `libnmmp.so` / `libnmmvm.so` | `lib/arm64-v8a/`（32 位镜像同有） |
| `com.nmmedit.protect.NativeUtil.classesInit0(N)` | 305 个类的 `<clinit>` |

命中类 315 个、方法 **1,165 个为 `native`**（字节码不在 dex，由 VM 解释执行）。
受影响范围：全部 Activity、整套设置层 `rc.*`、Compose UI 主体 `ed.* / cd.* / fd.*`。

**未被保护**：R8 合成 lambda 类（`a2 / hc / ec / ac / dd / oc / wa / gb / tc`）+ 全部第三方库。
→ 这是全局最关键的一条：判定调用点可能在 VMP 类里，但**被调用的校验函数本体常常仍落在明文类**。

典型样本（`SplashActivity`）：

```java
static { com.nmmedit.protect.NativeUtil.classesInit0(115); }
public final native void mo4390(z2.InterfaceC6745 p0, android.os.Bundle p1);   // 真身已被抽走
```

## 2. R8 混淆 + 自定义字符串加密（已完全破译）

- 10,766 个类，类名/方法名压成 `a2.C0036`、`ۥۖۗ۬۠ۤۜ` 一类乱码。
- 字符串加密算法（`y4.AbstractC6587.m12168`）：

```java
byte[] a = base64(s1), b = base64(s2);
for (int i = 0; i < a.length; i++) a[i] ^= b[i % b.length];   // 循环异或
return new String(a, UTF_8);
```

- 全树跑通后解出 **2,240 条有效明文**，含 107 个设置项键名、全部界面文案（Pro 功能清单即由此还原）、各设置类的原始 Kotlin getter 签名。

## 3. 权益（Pro）链路

```
MainCmpActivity.onResume()                                   ← 明文
 ├─ String s = rc.<授权类>.<getter>()                        ← 本地授权串, MMKV id="acbz"
 ├─ if (s 非空 && len>=5)
 │     if (ub.<校验类>.<verify>(HMAC生成器("LeidACoAd!@", 31天), s)) return;   ← 有效即跳过 Play
 │     if (ub.<校验类>.<verify>(HMAC生成器("LeidAC0Ad!@",120天), s)) return;
 └─ if ("gpBundle".contains("gp")) {                          ← 编译期 flavor 常量, 本包恒真
        BillingClient 单例 uc.C5946.f25694
        └─ queryPurchasesAsync("inapp") → uc.C5947.m11100(...)   ← 娜迦 VMP, native
   }
```

校验实现（**明文**）：

```java
public static boolean m11074(nj.C4374 gen, String s) {
    return s.equals(gen.m8473(System.currentTimeMillis()));
}
```

授权串本质是**时间步长 TOTP 码**，密钥硬编码 `LeidACoAd!@`（31 天）与 `LeidAC0Ad!@`（120 天）。

**Pro 功能面**（官方英文原文，解密所得）：主题外观 / Monet 取色、跳过启动页、截图水印与分享、MPV 播放器、PIP、跳过片头与预览缩略图；另有 `Restore Payment`、`Manage Subscription`。

## 4. 方案判定（**已修正**）

| 方案 | 结论 |
|---|---|
| 改 dex 里的权益/授权判定 | ✅ **可行**（原判"不可行"是错的）——判定**调用点**在 VMP 类里，但**校验函数本体 `ub.ۥۚۥۘۧ۠ۨ.ۥۜۛ۫ۦۦ` 是明文**，改为 `return true` 即整链贯通。教训：有 VMP ≠ 纯静态无效，先逐类确认哪些没被抽取。 |
| 重打包 + 重签 | ✅ 可行。娜迦的签名自校验（`getApkContentsSigners` / `getSigningCertificateHistory` / `hasMultipleSigners`）未拦截重签包；apktool 3.0.3 重建 targetSdk 36 资源需先修 `res/values-v34/colors.xml` 的私有色引用。 |
| 改 flavor 常量走非 Play 分支 | ✅ 保留（`gpBundle`→`xxBundle`），让应用自认非 Play 渠道包，配合校验恒真；连同其 XOR+base64 形态一起改键。 |
| 运行时 Hook（Frida） | 作为兜底保留（`yamby_pro.js`），最终未使用。 |

## 7. 最终结果

官方 arm64 单包（与 APKPure 32 位分片 base 的 `classes*.dex` **逐字节相同**）→ 移植同一套补丁 → 官方树重编译 → zipalign → 自签（V1+V2+V3，`yamby.keystore`）→ **用户实机验证 Pro 生效**。
